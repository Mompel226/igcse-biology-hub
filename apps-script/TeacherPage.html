The page address off

To create it once: Deploy ▸ New deployment ▸ ⚙ ▸ Web app, Execute as Me, Who has access Anyone within your school (not “Anyone”). Deploy, then paste the Web app URL below.

Open a student's tracker off

Paste the web app URL of any one of your reflection deployments (they all show the same tracker). The page then grows a Students tab where you pick a pupil and open their own reflection tracker — scores, weak topics, what to revise. Leave it empty and there is no Students tab.

Set homework off

Paste your hub's address — the one that serves its front page. It is usually a sub-folder, e.g. https://nlcsbiology.com/biology-hub, not the bare domain. Check it by opening <address>/js/data/labs.json: if that does not load, the address is wrong. It is read only to fetch the published list of each lab's stations — their names and how many questions each asks — which is what lets you pick parts of a lab to set as homework. No student data goes near it. Leave it empty and the Set homework page explains that it needs this.

Spreadsheets grouped by the cohort's graduation year

One row per spreadsheet. The graduation year is the cohort: this year's Y10 is 2028, next year's Y10 is 2029 — so the same test for another cohort is another row, and the page always shows the right year group on its own.

A test or a reflection also serves a live teacher dashboard at its own web-app address, ending /exec?page=dashboard. Put it here and the page offers it beside the spreadsheet, so nobody has to open the spreadsheet first to get to it.
