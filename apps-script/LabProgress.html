Lab progress

How each class is getting on with the labs — who has done what, where they are getting stuck, and how hard they are working at it. Read straight from the marks in the Student data spreadsheet.

This page only reads the marks; it changes nothing. Scores are averaged over the labs a student has actually handed in — a lab not yet started is shown as a blank in the grid, never counted as a zero, since with no set deadlines a missing lab may simply not have been assigned. Retries = how many times a station was checked; right first time = answered correctly on the first check. “Reviewed” ticks are kept in this browser only.
